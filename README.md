# Proyecto de Realidad Aumentada 🚗

## Descripción del proyecto
Este proyecto consiste en desarrollar una experiencia interactiva de realidad aumentada, donde, a través de la cámara de un dispositivo, se reconoce una imagen específica y se proyecta un automóvil en 3D sobre ella.

El objetivo es explorar cómo la realidad aumentada permite integrar elementos digitales en el entorno físico, creando una experiencia visual e interactiva.

## ¿Cómo funciona?
1. El usuario abre la experiencia de realidad aumentada.
2. La cámara detecta una imagen previamente definida.
3. Al reconocer la imagen, aparece un automóvil 3D sobre ella.
4. El automóvil se visualiza integrado al entorno real a través de la pantalla.

## Herramientas utilizadas
- Visual Studio Code
- HTML y JavaScript
- Tecnología de realidad aumentada basada en reconocimiento de imágenes
- Modelo 3D de un automóvil

## Desafíos del proyecto
Uno de los principales desafíos fue lograr que la cámara reconociera correctamente la imagen y que el automóvil apareciera en la posición y escala adecuadas.

También fue importante conseguir que el modelo se mantuviera alineado con la imagen al mover la cámara.

## Resultado final
Se desarrolló una experiencia de realidad aumentada en la que, al enfocar una imagen con la cámara, aparece un automóvil tridimensional sobre ella, combinando el mundo físico con elementos digitales.
